SUPUESTO I
El Ministerio de Educación, Formación Profesional y Deportes ha puesto en marcha el proyecto EDUCA-DATA 2030, cuyo objetivo es
diseñar, desarrollar e implantar un sistema integral para el seguimiento, análisis y toma de decisiones estratégicas sobre los diferentes
programas educativos.
El sistema permitirá la visualización de indicadores clave de rendimiento (KPI) relativos a centros educativos, programas formativos y
alumnado, entre otros muchos. La solución se integrará con los sistemas corporativos existentes mediante servicios REST y
procesamientos ETL, y almacenará la información en una base de datos Oracle Database 19c Enterprise Edition.
El desarrollo se realizará utilizando Java SE Development Kit (JDK) 17, Spring Boot 3.2.2, Apache Maven 3.9.6, un servidor de
aplicaciones Apache Tomcat 10.1.18 y un frontend basado en HTML5, CSS3 y JavaScript ECMAScript 2022. El control de versiones se
realizará con Git 2.43 y la integración continua mediante Jenkins 2.426.
Asimismo, el sistema incorporará funcionalidades de inteligencia artificial basadas en modelos de predicción implementados con Python
3.11 y TensorFlow 2.15 para anticipar riesgos de abandono escolar.
Además, la aplicación se integrará con una aplicación desarrollada en C# 14 y .NET 10 para obtener otros indicadores relevantes para
el sistema.
